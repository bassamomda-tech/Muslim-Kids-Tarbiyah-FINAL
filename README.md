# تربية الطفل المسلم — Muslim Kids’ Tarbiyah

منصّة تربوية إسلامية للأطفال، مبنية بالكامل بصفحات HTML تعمل دون أي خادم.
الصفحة الرئيسية للمشروع هي **`index.html`** في الجذر (خريطة المدينة).

---

## 🗺️ خريطة المشروع

```
/index.html                  ← الصفحة الرئيسية (خريطة المدينة)
/corners/                    ← كل الأركان (١٠ أركان موزّعة على ٤ تطبيقات)
```

---

## 📦 التطبيقات الأربعة داخل `corners/`

| المجلد | يحتوي الأركان | لماذا مجموعة معاً |
|--------|---------------|--------------------|
| `faith-minaret/` | منارة العقيدة | تطبيق مستقل (رحلة اليقين · التوحيد · الأمان · المعرفة · المختبر) |
| `heroes-fortress/` | حصن الأبطال · القلب السليم · الأكاديمية | الثلاثة يتشاركون نفس `engine/` و`data/` و`styles/` |
| `little-district/` | العبادة · القرآن · الحيّ · الرياضي · القدس · الأهل | صفحاتٌ داخل `pages/` تتشارك نفس `assets/` و`data/` |
| `activities/` | ركن الأنشطة (أنوس) | صفحة مستقلة قائمة بذاتها |

> **خلاصة:** ١ + ٣ + ٦ + ١ = **١٠ أركان** + ركن الأنشطة، داخل ٤ مجلدات.

## 🔗 التنقّل

- كل ركن فيه زرّ **«العودة للمدينة»** يعيدك إلى `index.html` في الجذر (وهو **الـ index الوحيد** في المشروع).
- خريطة المدينة (القائمة الجانبية 🗺️) داخل كل ركن تنقلك بين الأركان مباشرة.
- **مصدر واحد للقائمة:** كل قوائم الأركان تُبنى من مصفوفة `CORNERS` في
  `corners/shared/mk-system.js`. عدّلها **هناك مرّة واحدة** (إضافة/حذف/إعادة تسمية/ترتيب/أيقونة)
  وتتحدّث كل الأركان تلقائياً — لا حاجة لتكرار التعديل في كل ركن.
- داخل `corners/faith-minaret/` يوجد `nav-fix.js` يضمن عمل الروابط داخل المعاينة.

## 🧹 نسخة منظّفة

أُزيلت المواد المصدرية الخام (مجلّدا `uploads/` و`scraps/` ـ ~٣٠ ميغابايت من
الصور والملفّات المرجعية) لجعل المشروع صغيراً وسريعاً. لم تكن جزءاً من الموقع.

كما حُوِّلت الصفحات القديمة المكرّرة داخل `little-district/pages/` (العقيدة،
القلب، التاريخ، الأكاديمية) إلى **روابط تحويل** تُعيد التوجيه إلى نسخها
الأصلية المعتمدة — فلا روابط مكسورة، ولا محتوى قديم مكرّر.
