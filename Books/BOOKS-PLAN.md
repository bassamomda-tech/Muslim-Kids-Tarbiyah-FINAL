# Free-library books — plan (standard = «رحلة الصلاة»)

Every free-library journey becomes a print-ready story book built exactly like
`Books/Published/Worship Oasis/Salah Story Book.html`.

## The standard (every book gets all of this)
1. **Cover** (colour picture) + back cover + printer's wrap cover (spine width from page count).
2. **13 front-matter pages** (`corners/shared/book2/fm-<book>.js`): belongs-to · imprint ·
   contents · about us · values + five themes + ten corners · why this book (2 pages,
   evidence boxes from the site's verified data) · about this book + storytelling tips ·
   objectives & keywords table for every story · welcome letter from the heroes · special words.
3. **Every station = 4 pages**
   - two-page parchment story with a colour picture (heroes Yusuf 8 · Anas 9 · Maryam 7, rotating);
     every line of dialogue names its speaker;
   - «ماذا تعلّم البطل؟» page from the site's data: explanation, evidence + source,
     wrong idea put right, today's task, talk question;
   - colouring page (line art) or activity (sort, match, word search, true/false, order,
     tracker, write, draw, maze…).
4. End of book: spot-the-difference, true/false, answers, **two certificates** (boys / girls).
5. Arabic first, then the **English edition** (same pictures).
6. Checks before sending: no overflow, no tight vowelled Arabic, no code-drawn pictures,
   Islamic image rules (no prophets/Companions/angels drawn, full hijab, qiblah, men and
   women never in one row, no text in pictures).

Heroes Fortress / Seerah / Prophets books follow the Salah rule: the children hear the
stories from parents and grandparents; pictures show the children, places and objects — never
a prophet, Companion or angel.

## Suggested order
1. Finish Worship Oasis (books 2–4) — same corner as the standard.
2. Quran Garden (11–13) and the Forty Hadith (14–15).
3. Prophets and Seerah (25–26), then Our Little District (21).
4. Faith Minaret, then the remaining corners.

## Workflow for each book (repeatable)
1. I write the Arabic two-page stories, objectives and front matter from the site's data.
2. I send one prompt file for all the book's pictures (≈1 colour picture per story + line art
   for colouring pages + cover + spot-the-difference pair).
3. You generate them (≈20 a day) and send them; I place them and check them.
4. I build and check the PDFs (A4, print interior, print cover) → you review.
5. English edition from the same pictures.

**Pictures:** a 20-story book needs about 35 pictures (≈2 days); a 34-story book about 55
(≈3 days). The whole library is about 1,700 pictures.
