🎙️ دليل نشر التسميع الجديد

خادم Cloudflare Worker + Groq Whisper — بديلٌ رخيصٌ ومستقرٌّ عن Modal، بلا كروت رسومية ولا انهيارات. الوقت المتوقَّع: ١٥–٢٠ دقيقة.

💰 التكلفة: Groq يحسب ٠٫٠٤$ فقط للساعة من الصوت (نموذج Turbo) أو ٠٫١١$ للنموذج الأدق — أي أنّ التسميعة الواحدة تكلّف أجزاءً من السنت. وهناك باقة مجانية تكفي ٢٠٠٠ طلب يوميًّا. لا تكلفة عند عدم الاستخدام إطلاقًا (عكس Modal الذي يحاسب على وقت تشغيل الكرت الرسومي).
🛑 أولًا — أوقف خادم Modal القديم فورًا حتى لا يستهلك رصيدك: ادخل modal.com → التطبيق quran-asr → زر Stop app (أو احذفه). هو الآن «crash-looping» ويستهلك الرصيد في محاولاتٍ فاشلة.

١ أنشئ حساب Groq واحصل على المفتاح

  1. افتح console.groq.com وسجّل الدخول (بحساب Google مثلًا — مجاني، بلا بطاقة).
  2. من القائمة الجانبية اختر API Keys ← Create API Key.
  3. سمِّه quran-asr واضغط Create.
  4. انسخ المفتاح فورًا (يبدأ بـ gsk_...) واحفظه مؤقتًا — لن يظهر ثانيةً.

٢ أنشئ الـ Worker على Cloudflare

  1. افتح dash.cloudflare.com (لديك حسابٌ بالفعل).
  2. من القائمة الجانبية: Workers & Pages ← Create ← Create Worker.
  3. سمِّه quran-asr ثم Deploy (سيَنشُر مثالًا افتراضيًّا مؤقتًا).
  4. اضغط Edit code (تحرير الكود).
  5. احذف كل الكود الموجود، ثم افتح ملف server/quran-asr-worker.js (من الملفات التي حمّلتها) في أي محرّر نصوص، انسخه كاملًا والصقه في المحرّر.
  6. اضغط Deploy (أعلى اليمين).

٣ أضِف المفتاح السرّي للـ Worker

  1. ارجع لصفحة الـ Worker ← Settings ← Variables and Secrets (أو Variables).
  2. تحت Secrets اضغط Add:
    • الاسم (Variable name): GROQ_API_KEY — بالضبط بهذا الشكل.
    • القيمة (Value): الصق مفتاح Groq (gsk_...).
  3. اضغط Deploy / Save.
  4. اختياري (لحماية أفضل): أضِف متغيّرًا عاديًّا (Variable) باسم ALLOWED_ORIGINS وقيمته نطاق موقعك، مثل: https://yoursite.com,https://www.yoursite.com — يمنع غيرك من استهلاك رصيدك.
  5. اختياري: متغيّر MODEL = whisper-large-v3-turbo إن أردت الأرخص والأسرع (الافتراضي whisper-large-v3 الأدقّ).

٤ انسخ رابط الـ Worker

  1. في صفحة الـ Worker ستجد الرابط أعلى الصفحة، بالشكل:
    https://quran-asr.YOURNAME.workers.dev
  2. انسخه.
💡 للتأكّد أنه يعمل: افتح الرابط في المتصفح — يجب أن تظهر رسالة {"error":"post_audio_only"}. هذا طبيعيٌّ وصحيح (لأن المتصفح يفتحه كطلب GET لا POST).

٥ اربط الموقع بالخادم الجديد

  1. افتح ملف corners/quran-hifz/asr-client.js.
  2. في السطر الرابع تقريبًا، ضع الرابط بين علامتَي التنصيص:
    var ASR_ENDPOINT = 'https://quran-asr.YOURNAME.workers.dev';
  3. احفظ الملف.

٦ ارفع الملفات المعدَّلة

ارفع هذه الملفات إلى موقعك (بنفس مساراتها):

  • corners/quran-hifz/asr-client.js ← فيه الرابط + تمرير الآية المتوقَّعة
  • corners/quran-hifz/index.html ← يمرّر الآيةَ المتوقَّعة للخادم

ثم افتح ركن الحفظ واعمل تحديثًا قسريًّا: Ctrl+Shift+R (أو أعد فتح التبويب على الجوال).

٧ جرّب — وحلّ المشكلات

  • ادخل سورةً قصيرة، اضغط 🎤 «تسميع»، واقرأ. يجب أن تتلوّن الكلماتُ الصحيحة تلقائيًّا.
  • لا يستجيب / يرجع للمحرّك القديم؟ راجع أنّ الرابط في asr-client.js صحيح، وأنّ اسم السرّ GROQ_API_KEY مطابق تمامًا.
  • خطأ في Cloudflare؟ افتح الـ Worker ← Logs ← Begin log stream وراقب الأخطاء أثناء التجربة. رسالة groq_error 401 تعني أنّ المفتاح خاطئ؛ groq_error 429 تعني تجاوز الباقة المجانية (فعّل الدفع في Groq).
  • الدقة: صار الخادم يستقبل الآيةَ المتوقَّعة ويوجّه بها Whisper — هذا يرفع الدقة كثيرًا على نفس الآية، ويقلّل الخلط مع الضوضاء.

ملاحظة أمينة عن الدقة: هذا الحلّ رخيصٌ ومستقرٌّ ويستغلّ أنّنا نعرف الآيةَ المطلوبة مسبقًا، فيقترب كثيرًا من جودة Tarteel. لكن مطابقة دقّتهم الكاملة (٤٪ خطأ) تحتاج نموذجًا قرآنيًّا متخصّصًا. إن لم تكفِك الدقة بعد التجربة، الخطوة التالية هي استضافة نموذج tarteel-ai/whisper-base-ar-quran المفتوح — أخبرني وقتها ونفعلها.
