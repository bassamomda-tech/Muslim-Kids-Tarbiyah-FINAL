# معسكر القادة — Leaders' Camp

قسم خاص بالأسرة داخل الموقع. غير مرتبط من أي صفحة، ولا يظهر في محركات البحث (`noindex`)، ولا يحتوي الكود على أي اسم: الأسماء تُكتب على الجهاز وتُحفظ في حساب الأسرة فقط.

الرابط: `/camp/` · شاشة البيت: `/camp/#/tv`

## الملفات
| الملف | الغرض |
|---|---|
| `index.html`, `camp.css` | الصفحة والمظهر |
| `data.js` | النصوص (عربي/إنجليزي)، المهام، الرتب، الجوائز، جواز المواهب، الدستور |
| `adhkar.js` | الأذكار المسموعة ومعانيها |
| `weeks.js` | خطة الأسابيع الـ٢٤ (منقولة من صفحة منهج الأسرة) |
| `prayer.js` | حساب مواقيت الصلاة |
| `store.js` | الحالة، الحفظ المحلي، المزامنة عبر Firestore، تسجيلات الصوت (IndexedDB) |
| `app.js`, `views.js`, `parent.js` | الشاشات |

## تفعيل المزامنة بين الأجهزة (مرة واحدة)
1. انشر قواعد Firestore (أضيفت قاعدة `camp/{uid}` في `firestore.rules`):
   `firebase deploy --only firestore:rules`
2. من «الوالدان ← المزامنة» سجّل الدخول بحساب الموقع (أو أنشئ حسابًا للأسرة).
3. على كل جهاز آخر: افتح `/camp/` وسجّل الدخول بالحساب نفسه.

بدون تسجيل دخول يعمل المعسكر على الجهاز محليًا (`localStorage`).

## البيانات
مستند واحد لكل حساب: `camp/{uid}` — لا يقرؤه ولا يكتبه إلا صاحب الحساب.
`family`, `kids`, `log[date][kid][mission]`, `adj`, `red`, `bank`, `pass`, `goals`, `prop`.
تسجيلات الصوت تبقى على الجهاز ولا تُرفع.

## مصادر خارجية
- تلاوة القرآن: `everyayah.com` (يحتاج اتصالًا).
- نص السور وترجمتها: `corners/quran-hifz/quran-data/` من الموقع نفسه.
- نطق الأذكار: قارئ الجهاز (SpeechSynthesis) بالعربية.
